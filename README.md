# Ejercicios del examen

Las respuestas están en [`resultados/`](resultados/), un PDF por agente. El nombre indica ejercicio, tema y modelo; `_revisado` es la versión corregida por el revisor y `_REVISAR` marca un certificado numérico que falló.

| Carpeta | Uso |
|---|---|
| [`agentes/`](agentes/) | instrucciones de cada agente y datos del examen |
| [`espacio_de_trabajo/`](espacio_de_trabajo/) | lo que escriben los agentes (.tex) y las revisiones |
| [`resultados/`](resultados/) | solo PDFs compilados |

_Aún no hay ejercicios cargados._
